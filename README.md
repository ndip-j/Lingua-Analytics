\# Linguaspan Analytics Practice

This repository contains my Week 1 data analytics practice using mock transcript data.


\## Files

\- `word\_counter.py` - counts words in each transcript

\- `week1\_analysis.py` - Pandas exploration and analysis

\- `linguaspan\_mock\_transcripts.csv` - mock transcript dataset


\## Week 1 Findings

English and Yoruba had the highest number of transcripts, with 17 each, followed by Hausa with 16 and Igbo with 10.

Speaker E had the highest total word count at 210 words, followed by Speaker C with 171 and Speaker D with 169.

Hausa transcripts had the longest average duration, at about 116.9 seconds, while English had the shortest average duration at about 94.1 seconds
